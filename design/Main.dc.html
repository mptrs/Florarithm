Florarithm

FOUNDATIONS

A herbarium ledger on a phone. Warm paper ground, ink-black text, one saturated colour per meaning. Names are set in a serif like a specimen label; everything a machine produced — codes, dates, day counts — is set in mono so it lines up and stays comparable down a column.
